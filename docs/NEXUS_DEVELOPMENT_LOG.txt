## Agreed architecture
**PostgreSQL → Scheduler → Transactional Outbox → Reliable Publisher → Redis/BullMQ regional queues → Regional Workers → PostgreSQL**, with a reconciler repairing missing or stuck work.

Key guarantees and decisions:
- PostgreSQL is the durable source of truth; Redis/BullMQ is delivery infrastructure.
- Separate India (`ap-south-1`) and USA (`us-east-1`) queues/workers.
- At-least-once delivery with idempotent database effects; no exactly-once claim.
- Logical scheduled executions are distinct from queue delivery/retry attempts.
- Scheduler persists execution + outbox intent atomically and does not perform HTTP checks.
- No database transaction remains open during an external HTTP request.
- Bound concurrency, database pools, batches, regional throughput and per-target request rates.
- Coalesce missed schedule intervals rather than enqueueing every obsolete interval.

See the architecture document for full state machines, schema details, transaction boundaries, failure analysis, security and design decisions. Do not change approved architecture without review and explicit agreement.
